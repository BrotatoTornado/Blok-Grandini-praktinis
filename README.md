# Blok-Grandini-praktinis

Atskirų sekcijų maiša paremta sudėtim, baitų pajudinimu (šiftinimu) į kairę, XOR su kaimynine sekcija ir Golden Ratio konstantos daugyba (nelyginė). Lavinos efektas stipresnis kuo didesnė įvestis. Newline "\n" ("enter") neįtraukiamas.

Riba yra laisva RAM apimtis. Nepriima kitų išskyrus UTF-8 įvesčių.
